Roteiro de laboratório

Ambiente de desenvolvimento C com Allegro 5

Ao final deste roteiro, você terá um projeto em C que abre uma janela gráfica com a biblioteca Allegro 5, compilando e rodando no seu computador com Windows.

1. Apresentação

Allegro 5 é uma biblioteca multiplataforma para jogos e aplicações multimídia. Ela cuida de janela, teclado, mouse, imagens, fontes, sons e temporizadores, e é escrita em C.

O roteiro traz dois caminhos independentes. Siga apenas um: a Parte A (Visual Studio) ou a Parte B (VS Code). Depois, todos seguem juntos a partir da seção 5.

2. Pré-requisitos

Você precisa de um computador com Windows 10 ou 11 (64 bits), acesso de administrador e internet durante a instalação.

  • Espaço em disco: cerca de 8 GB para o Visual Studio, ou cerca de 2 GB para VS Code + MSYS2.
  • Conhecimento prévio: saber criar pastas, abrir o terminal e compilar um "Olá, mundo" em C.
  • Pasta de trabalho: crie uma pasta sem espaços nem acentos no caminho, por exemplo C:\projetos\allegro. Caminhos como C:\Users\João\Área de Trabalho causam erros de compilação e de linkagem.
A 3. Parte A — Visual Studio Allegro instalado pelo NuGet, compilador da Microsoft

No Visual Studio, o Allegro é instalado pelo gerenciador de pacotes NuGet, recomendado pela wiki oficial do Allegro. A versão mais recente no NuGet é a 5.2.11.2.

A.1 Instalar o Visual Studio

  1. Baixe o Visual Studio Community (gratuito) em visualstudio.microsoft.com. Use a versão 2022 ou mais recente.
  2. No instalador, marque a carga de trabalho Desenvolvimento para desktop com C++.
  3. Clique em Instalar e aguarde. Reinicie o computador se for solicitado.

A.2 Criar o projeto

  1. Abra o Visual Studio e clique em Criar um projeto.
  2. Escolha o modelo Projeto Vazio (linguagem C++). Não existe um modelo "C"; o compilador trata arquivos .c como C automaticamente.
  3. Dê o nome JogoAllegro, salve em C:\projetos\allegro e clique em Criar.
  4. No Gerenciador de Soluções, clique com o botão direito em Arquivos de Origem → Adicionar → Novo Item.
  5. Nomeie o arquivo como main.c (com extensão .c, não .cpp) e clique em Adicionar.
  6. Na barra superior, confirme que a plataforma está em x64.

A.3 Instalar o Allegro pelo NuGet

  1. Clique com o botão direito no projeto (não na solução) → Gerenciar Pacotes do NuGet.
  2. Abra a aba Procurar e pesquise Allegro.
  3. Selecione o pacote Allegro e clique em Instalar. O pacote AllegroDeps vem junto automaticamente.

A.4 Configurar o Allegro no projeto

  1. Clique com o botão direito no projeto → Propriedades.
  2. No topo da janela, selecione Configuração: Todas as Configurações e Plataforma: Todas as Plataformas.
  3. Abra o item Allegro 5 que apareceu na lista à esquerda.
  4. Em Library Type, escolha Dynamic Debug - Dynamic Runtime (para começar).
  5. Em Add-ons, mude para Sim os módulos que o projeto vai usar:

A.5 Compilar e executar

  1. Cole o programa de teste da seção 5 em main.c.
  2. Pressione F5 (depurar) ou Ctrl+F5 (executar sem depurar).
  3. Uma janela preta com um quadrado laranja deve aparecer. Se aparecer, vá para a seção 5 para entender o código.

Dica: se o compilador reclamar de scanf ou fopen "inseguros" (aviso C4996), adicione #define _CRT_SECURE_NO_WARNINGS na primeira linha do main.c.

B 4. Parte B — VS Code GCC e Allegro instalados pelo MSYS2

No VS Code, o compilador GCC e o Allegro vêm do MSYS2, que instala o pacote mingw-w64-ucrt-x86_64-allegro (versão 5.2.11.1). O VS Code é só o editor; ele chama o GCC por meio de arquivos de configuração na pasta .vscode.

B.1 Instalar o MSYS2

  1. Baixe o instalador em msys2.org e instale no caminho padrão C:\msys64.
  2. Ao final, abra o terminal MSYS2 UCRT64 pelo menu Iniciar. Use sempre esse terminal nesta parte.
  3. Atualize o sistema. Se o terminal fechar sozinho, abra de novo e repita o comando até não haver mais atualizações:

B.3 Colocar o compilador no PATH do Windows

Sem este passo, o VS Code não encontra o gcc e o jogo não encontra as DLLs do Allegro.

  1. No menu Iniciar, pesquise Editar as variáveis de ambiente para sua conta.
  2. Em Variáveis de usuário, selecione Path → Editar → Novo.
  3. Digite C:\msys64\ucrt64\bin e clique em OK nas três janelas.
  4. Abra um Prompt de Comando novo e teste gcc --version. Se aparecer a versão, está certo.

B.4 Instalar o VS Code e a extensão de C

  1. Baixe e instale o VS Code em code.visualstudio.com. Marque a opção Adicionar ao PATH no instalador.
  2. Abra o VS Code, vá em Extensões (Ctrl+Shift+X) e instale C/C++ (da Microsoft).
  3. Em Arquivo → Abrir Pasta, abra C:\projetos\allegro\JogoAllegro (crie a pasta antes).
  4. Crie o arquivo main.c na raiz da pasta e uma subpasta chamada .vscode.

5. Programa de teste

Este programa abre uma janela de 800×600, desenha um quadrado laranja que se move com as setas e fecha com ESC ou no X da janela. Ele usa os add-ons Font e Primitives; no Visual Studio, confirme que os dois estão como Sim (seção A.4).

O código segue a estrutura que todo projeto Allegro terá:

EtapaO que fazFunções principais
1. InicializaçãoLiga a biblioteca, o teclado e os add-onsal_init, al_install_keyboard, al_init_*_addon
2. RecursosCria janela, timer, fila de eventos e fonteal_create_display, al_create_timer, al_create_event_queue
3. Fontes de eventosDiz à fila de onde vêm os eventosal_register_event_source
4–5. Laço principalEspera eventos e atualiza o estado a cada tique do timeral_wait_for_event
6. DesenhoLimpa a tela, desenha e troca o bufferal_clear_to_color, al_draw_*, al_flip_display
7. EncerramentoLibera memória e fecha a janelaal_destroy_*

O texto desenhado na tela usa a fonte embutida do Allegro, que só tem caracteres ASCII. Para usar acentos, carregue um arquivo .ttf com al_load_ttf_font e salve o main.c em UTF-8.
